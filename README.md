# Pizza Lab
## Pizza what?
Pizza Lab is a service that monitors your P1S.

### ...Bambu Studio? Bambu Handy? This tool is useless!
Some people like me don't want to use so much energy.

### Well then, how do I set it up as a service!
First off, run `setup.sh`.

Second, you yourself create a service that opens Firefox @ localhost:2080 as kiosk on boot.

Good job. You did it.

## What can it monitor?
Nozzle temperature, bed temperature, the MQTT chitchat, and AMS colors.

It can also monitor print time, print percentage, and print speed.
